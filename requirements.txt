# FallGuard AI — Streamlit Cloud serving dependencies
#
# Every pin here is deliberate; the combination below is the one that actually
# resolves. Read before changing anything:
#
#   mediapipe 0.10.18  — the 1.x line removed `mp.solutions.pose` in favour of
#                        the Tasks API, which downloads its model bundle from
#                        the network on first call. 0.10.x ships BlazePose
#                        inside the wheel, so there is no cold-start download.
#   protobuf 4.25.x    — required by mediapipe 0.10.x (<5). This is the pin
#                        that forces the Streamlit ceiling below.
#   streamlit 1.44.1   — the newest release still allowing protobuf<6.
#                        Streamlit >=1.45 requires protobuf>=5.26 and will
#                        break MediaPipe.
#   numpy <2           — mediapipe 0.10.x is not built against the NumPy 2 ABI.
#   opencv ...-headless — the non-headless build needs libGL, which is absent
#                        from the Streamlit Cloud image.
#   opencv-contrib-python 4.10.0.84
#                      — PINNED BECAUSE IT TOOK THE APP DOWN IN PRODUCTION.
#                        mediapipe declares this dependency with no upper
#                        bound. OpenCV 5.0.0.93 was published, the container
#                        was rebuilt, pip took the new major version, and
#                        `import cv2` started failing on a missing libGL.so.1
#                        — with no change to this repository at all.
#
#                        Every OpenCV wheel unpacks into the same `cv2/`
#                        directory, so pinning opencv-python-headless below is
#                        not sufficient on its own: whichever wheel is
#                        installed last wins, and the contrib build is the GUI
#                        one. Pinning BOTH keeps a single, consistent 4.x
#                        install regardless of resolution order.
#
#                        There is a second reason to stay on 4.x. The browser
#                        rasteriser in assets/live_monitor.js reproduces
#                        `cv2.line(..., 2, LINE_AA)` arithmetically, and its
#                        capsule radius (1.65 px) was fitted by measuring THIS
#                        OpenCV version. A major-version bump could change the
#                        antialiasing and silently shift every tensor the CNN
#                        sees away from what it was trained on. That would not
#                        crash — it would just quietly get worse, which is
#                        harder to notice and much harder to debug.
#
# See packages.txt for the belt-and-braces half of this fix, and
# scripts/selftest.py [11] for the regression guard that fails the build if an
# unbounded transitive dependency ever reappears.
#
# TensorFlow is deliberately ABSENT. The CNN is trained with Keras in the
# notebook, then exported to plain NumPy weights (models/fallguard_cnn.npz) and
# served by src/cnn_numpy.py. That keeps the container small and fast to start.
# To retrain, install requirements-dev.txt as well.
